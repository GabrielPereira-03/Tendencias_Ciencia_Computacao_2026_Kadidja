## 📐 Sistema de Navegação (Avaliação)

A pontuação do semestre é dividida da seguinte forma:

$$\text{Nota Final (NF)} = \text{A1 } (5,0) + \text{A2 } (5,0) = 10,0 \text{ pts}$$

* **A2 (5,0 pontos):** Composta por atividades práticas continuadas (10 atividades x 0,5 pt = 5,0 pts) e prova teórico-prática.
* **A1 (5,0 pontos):** Projeto final em grupo de desenvolvimento de solução inteligente e reflexão de aprendizagem.

### 🏁 Condições de Pouso (Aprovação):
* **Nota Final (NF) $\ge$ 6,0**
* **Frequência $\ge$ 75%**

### ⚠️ Protocolo de Emergência (Recuperação):
* Caso a Nota Final seja inferior a 6,0 ($\text{NF} < 6,0$), o estudante poderá realizar a **Avaliação Final (AF)** nas datas estipuladas, a qual substituirá a menor nota obtida no semestre.
